
# Student Management System

## Project Description

The Student Management System is a web-based application
used to manage student information easily.

It allows users to add, view, update, delete and search
student records.

## Features

1. Add Student Details
2. View Student Records
3. Update Student Details
4. Delete Student Records
5. Search Student Information
6. Save Records Using Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## Project Structure

student-management-system/

- public/
  - index.html

- README.md

## CI/CD Implementation

GitHub Actions is used to automate project testing.

The pipeline checks the required files, validates
JavaScript syntax and verifies website content.

After successful testing, GitHub Pages automatically
deploys the website.

## How to Run

1. Clone the repository.
2. Open the public folder.
3. Open index.html in a browser.

## Result

The Student Management System successfully manages
student records and uses GitHub Actions for automated
testing and deployment.
